# 管理员访问密钥

本文描述独立管理员 Key 的生命周期、资源授权、响应裁剪和事务边界。普通网关 Key、用户登录会话与团队成员授权分别由其它领域文档拥有。

## 生命周期与身份

独立 Key 使用 `adm_sc_` 前缀，数据库 `scoped_admin_api_keys` 只保存摘要和公开前缀。创建、轮换后只返回一次完整凭据；列表、审计和错误均不返回完整 Key。每次请求重新读取 Key，检查启用、撤销、有效期与 IP/CIDR 规则，并读取创建者当前的 active admin 身份，不使用可长期复用的授权缓存。

`/api/v1/admin/settings/admin-api-keys` 的查询、创建、更新、轮换、撤销及隐藏记录只允许管理员 JWT。写操作经过现有 step-up；旧单一管理密钥的轮换与删除也执行同一门控。全权 Key 仍不能管理密钥生命周期。撤销不可恢复，隐藏列表项不物理删除原记录或审计。更新与轮换使用版本或摘要 CAS，旧并发请求不能恢复已经收回的授权。

## 授权与输出

每条资源规则同时包含动作、分组、账号类型和平台，四者必须在同一条规则内匹配，不能将多条规则拼成更宽的授权。支持十四个平台及 Qoder `cosy` 类型。无分组账号必须显式选择 `include_ungrouped`；选择全部分组不自动包含未分组账号。分组级模型管理不使用账号类型条件，但分组与平台仍须同规则匹配。

`adminaccess` 按 HTTP 方法和 Gin 完整路径逐条登记动作，未登记接口默认拒绝。全站权限独立于资源规则，选择某个分组不授权全站报表、财务或用户操作。fork 的团队、发票、数据共享、存储、备份和调度诊断在 `fork_catalog.go` 显式登记；这些全站权限的产品标签说明读取范围或敏感资料，不能按路径前缀自动扩展新接口。

受限账号处理器独立校验资源与字段。列表在 SQL 中过滤完整规则并分页，只投影允许的身份、模型映射、模型白名单和用量子字段，不读取完整凭据。账号模型权限保留 fork 的 `model_mapping` 与 `model_whitelist` 两种独立配置。写凭据使用补丁合并，不能因脱敏表单缺键清除其它连接配置。共享账号的关联变更只替换授权范围内的关系，保留其它分组及关联元数据；影子账号和持有影子的母账号不开放受限修改。

用户资料、余额、平台额度、订阅、用量和内容读取分别授权。写操作只确认必要结果，不顺带返回关联用户、完整分组、上游凭据或其它未授权数据。幂等指纹包含 Key 身份及当前策略；重放后仍执行响应裁剪，权限变化不能取回旧的宽响应。订阅裁剪使用 fork 的套餐 `plan_id` 及额度快照，不恢复上游旧分组订阅字段。

## 事务与副作用

受限资源写入在事务内锁定账号与关联，并重新检查实际资源。来自真实认证的 Key 版本还会在资源事务内与创建者身份共同复核并持共享锁至提交；撤销、轮换、收权或创建者停用后，旧请求不能提交账号或分组模型写入。

账号仓储同时切换 ORM 与原生 SQL 到调用方事务，事务内不发布调度快照。`AfterAccountCommit` 将 token 缓存失效、隐私设置和运行时解封推迟至提交成功；回滚不执行。持久调度 outbox 随数据库事务提交，成功返回前补发实际账号快照更新或删除。

额度统计只读权限不会触发模型探测、自动恢复或自动消费重置次数。读取影子账号的共享额度必须同时拥有母账号对应权限；刷新凭据和重置次数是独立动作。异步快照及共享查询保留授权上下文，重新读取资源时再次检查。

## 管理端与审计

安全设置页提供独立 Key 表单，支持多条范围规则、IP、到期时间和全站动作。分组选择复用项目 `GroupSelector`，平台和账号类型明确勾选。全权兼容模式需要单独确认；切换语言后清除尚未保存的扩权确认。

受限 Key 的每次请求均记录 Key ID、名称、创建者、结果与拒绝原因，常规请求体审计不再重复保存凭据。额外审计字段只接收允许的非敏感标量，禁止通过任意对象附加原始正文或 token。
